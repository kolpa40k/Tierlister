# Tier List Maker

Десктопный редактор тир-листов на Go и Fyne 2.8.2 для Windows и Linux.

## Возможности

- Категории и тир-листы с уровнями S, A, B, C и D.
- Импорт изображений из файлов и буфера обмена (кнопка и Ctrl+V).
- Перетаскивание изображений из нижнего пула в тиры, между тирами и обратно.
- Перестановка изображений внутри тира и изменение их подписей.
- Очистка неиспользуемых файлов изображений с предварительным просмотром.

**Управление изображениями:** щёлкните правой кнопкой мыши по карточке, чтобы открыть меню переименования, удаления или возврата в пул. Кнопки поверх изображений убраны, чтобы они не закрывали содержимое.

## Сборка

Требуется Go версии, указанной в `go.mod`, и системные зависимости Fyne для выбранной ОС.

```bash
go mod download
go test ./...
go vet ./...
golangci-lint run ./...
go build -o tier-list-maker .
```

На Linux с Wayland для вставки из буфера требуется `wl-paste` из пакета `wl-clipboard`.

## Хранение данных

Для совместимости с предыдущими версиями данные находятся в `~/.tierlist-app` (на Windows — в домашнем каталоге пользователя): `categories.json`, `settings.json`, каталог `images/`.

Изображения в пуле и тирах хранятся в одной папке; их расположение в редакторе описывается в JSON. Команда «Очистить файлы» удаляет только неиспользуемые изображения, принадлежащие приложению. Перед массовой очисткой рекомендуется сделать резервную копию каталога данных.

## Проверка интерфейса

Проверяйте на реальном экране: отображение подписей и пропорций изображений, фиксированную высоту строк, перетаскивание при прокрутке и масштабировании, вставку из буфера и переключение тем. Нативную работу под Wayland можно проверить через `hyprctl clients -j` (поле `xwayland` должно быть `false`).

## Отображение изображений

В редакторе каждого тир-листа есть настройки **«Подписи»** и **«Заполнить / Вместить»**.
Они сохраняются отдельно для каждого списка. «Заполнить» обрезает края
изображения, не оставляя пустых полос; «Вместить» показывает его целиком
на графитовом фоне. Отключение подписей не удаляет названия из данных.
Горизонтальная прокрутка тиров размещается под карточками.

## Отображение изображений

В редакторе доступны переключатель подписей и режимы «Заполнить»/«Вместить».
Настройки сохраняются для каждого тир-листа отдельно. Прозрачность PNG сохраняется:
фон карточки рисуется отдельно и не добавляется в файл изображения.
При построении миниатюры автоматически убираются только однородные почти белые
горизонтальные поля по верхнему и нижнему краю (не более четверти высоты с каждой стороны).
Оригинальные изображения при этом не изменяются.

Карточки имеют постоянную геометрию 112×128, без внутренних отступов между
изображением и подписью. Если подписи отключены, картинка занимает всю карточку.

## Прозрачность изображений

При импорте PNG и WebP альфа-канал сохраняется в создаваемом PNG-файле. Прозрачные области отображают фон карточки, а не белую подложку. Исходные файлы не изменяются.

Изображения, импортированные старыми версиями с белой подложкой, необходимо импортировать заново из оригиналов: утраченная прозрачность не восстанавливается автоматически.
